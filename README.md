# SAÉ 3.02 — Quiz de cybersécurité

## Présentation du projet

Ce projet est réalisé dans le cadre de la SAÉ 3.02 « Développer des applications communicantes ».

L'objectif est de développer une application de quiz portant sur l'hygiène informatique et l'initiation à la cybersécurité.

## Objectifs

- Créer, modifier et supprimer des questions.
- Permettre aux utilisateurs de passer des quiz.
- Stocker les questions et les réponses dans une base de données locale.
- Développer un site web communiquant avec la base de données.
- Exporter les questions et les réponses au format JSON.
- Récupérer les questions et les réponses au format JSON depuis d'autres sites de quiz.

## Technologies

- Java
- Base de données locale (à définir)
- HTML, CSS et JavaScript
- JSON
- Git et GitHub
